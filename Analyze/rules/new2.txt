2. FUNCTIONAL SPECIFICATIONS
========================================================================
[FN-301] HORIZONTAL SCROLL INTERACTION (SCROLL-SNAP)
- Input Source: User touch swipe gesture or mouse wheel trackpad delta-X scroll vector inside container [LY-301].
- Logic: Translates viewport horizontally across flex cards using CSS properties:
         `display: flex; flex-direction: row; flex-wrap: nowrap; overflow-x: auto; scroll-snap-type: x mandatory;`
- Constraints: Multi-row wrapping is strictly disabled. Cards must snap smoothly into exact horizontal alignments to prevent partial card clippings.

[FN-302] CATEGORY ROUTE REDIRECTION
- Input Source: Primary pointer click or tap execution on any card component block ([LY-302] through [LY-309]).
- Logic: Triggers router history push event routing user to corresponding category catalog view (e.g., `/portfolio/print`, `/portfolio/web-design`).

========================================================================
3. UI/UX INTERACTION MECHANICS
========================================================================
[LY-302 through LY-309] STRICTOR HORIZONTAL LAYOUT BOUNDS
- [Idle State]: Scale factor at 100%, flex-shrink set to 0 to maintain absolute widths along the row axis, soft structural shadow.
- [Loading State]: Skeleton pulse loader animation blocks replacing specific card thumbnail items.
- [Success State]: High-resolution category preview images loaded with subtle zoom scale transition on hover (`scale(1.03)`).
- [Error State]: Renders default fallback thumbnail graphic box with corresponding text title remaining intact.
