[STRICT DIRECTIVE] Every button component generated, modified, or merged 
MUST inherit the '.premium-btn' style architecture. The "Sharp Glass Pane" 
full-width responsive sweep is mandatory across all size and color models.

1. THE COMPRESSED 3-COLOR MATRIX (INVARIANT COLOR SPACE)
   Every button must select exactly ONE of these three color systems:

   🔴 SYSTEM A: PRIMARY TEAL (Action, Search, Nav)
     - Tailwind Classes: 'bg-primary text-on-primary' (mapping to '--color-primary' / #266F71).
     - Context: Standard page interactions and routing triggers.

   🟠 SYSTEM B: ACCENT CORAL (High-Impact Conversion)
     - Tailwind Classes: 'bg-accent text-white' (mapping to '--color-accent' / #FB8E5D).
     - Context: Conversion triggers, forms, and high-impact action buttons.

   ⚪ SYSTEM C: GHOST TRANSPARENT (Contrast/Image Overlays)
     - Tailwind Classes: 'bg-white/10 backdrop-blur-md border border-white/30 text-white'.
     - Context: Floating elements sitting directly over rich visual imagery or backdrops.

2. DYNAMIC GEOMETRIC CLASSIFICATION (WIDTH-AGNOSTIC PADDING)
   Adjust button scales strictly using layout padding constraints:
   - SMALL (e.g., Grid Actions): 'px-6 py-2 rounded-lg text-label-sm'.
   - STANDARD (e.g., Navbar): 'px-8 py-3 rounded-lg text-label-lg'.
   - LARGE (e.g., Search CTA): 'px-12 py-4 rounded-xl text-label-lg'.
   - BLOCK (e.g., Full Form): 'w-full py-5 rounded-xl text-label-lg'.

3. STYLESHEET REFACTOR: SIZE-AGNOSTIC SHARP DIAGONAL SWEEP (BUTTON B)
   Apply this exact CSS configuration to eliminate corner clipping or pooling.
   The 400% canvas footprint guarantees the 45-degree edge crosses any layout width.

   .premium-btn {
     position: relative;
     overflow: hidden;
     transition: all 0.4s cubic-bezier(0.165, 0.84, 0.44, 1);
     font-family: var(--font-sans); /* Force universal Inter font alignment */
     text-transform: uppercase; /* Force universal clean-casing */
     letter-spacing: 0.05em;
     cursor: pointer;
     border: 1px solid rgba(255, 255, 255, 0.1);
   }

   /* Responsive Button B Sharp Glass Pane Overlay */
   .premium-btn::after {
     content: '';
     position: absolute;
     top: -150%;
     left: -150%;
     width: 400%;
     height: 400%;
     background: linear-gradient(
       to right,

   }

     /* Motion Fix: Sweeps dynamically across both axes from Right-to-Left down to bottom-left */

   }

   /* Active Click Press Dynamics */
   .premium-btn:active {
     transform: translateY(0px) scale(1.0);

   }
